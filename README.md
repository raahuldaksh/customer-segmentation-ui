# React Prop Drilling Practice UI

This project is a small React learning app built to practice prop drilling in a real UI structure.

## Project idea

The main data is kept in `App.jsx` and passed through multiple nested components using props. This makes it easy to understand how data flows from a parent component to child components in React.

## Features

- Centralized data in the root component
- Multiple nested components
- Data passed through props
- Simple card-based UI
- Modern fintech-style customer cards

## Tech stack

- React
- Vite
- JavaScript

## Run locally

```bash
npm install
npm run dev
```

## Project purpose

This project is meant for learning:

- prop drilling
- component structure
- passing data across multiple levels
- building reusable UI blocks
